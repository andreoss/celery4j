= celery4j

A Java 17 library that speaks the Celery task protocol: send tasks to Celery
workers, run the tasks Celery sends, and read the results either side leaves
behind. No bridge, no adapter, no Python in the way.

* Celery protocol version 2 and version 1, bodies in JSON
* Redis and AMQP brokers
* Results with their states, values and failures
* A worker that runs what it is handed, with retries and time limits

== Build

----
mvn verify           # its own cases, and the quality gate
mvn verify -Plive    # adds the cases that talk to Celery and to real services
----

Needs Java 17 to run, a newer one to build, and a container runtime for the
live cases.
